# Проект «Образование»

Персональный адаптивный образовательный навык, тематические модули и локальные
учебные инструменты.

## Структура

- `skill/education-project/` — общий педагогический слой и тематические модули;
- `plugins/moex-futures-education/` — read-only MCP для официального MOEX ISS;
- `outputs/futures-learning-lab/futures-learning-lab.xlsx` — учебная книга для
  бумажной практики фьючерсов;
- `.agents/` — локальная регистрация навыка и проектного плагина.

## Границы

- Проект не содержит брокерского исполнения или торговых ключей.
- Данные MOEX ISS используются только для чтения и могут быть отложенными.
- Проект «Инвестиции», его портфель и персональные финансовые ограничения сюда
  не переносятся.
- `sources/` не публикуется: папка синхронизируется отдельно и может содержать
  приватные или лицензированные материалы.

## Проверка

Перед обновлением навыка запускать валидатор навыка и связанные регрессионные
проверки. При изменении учебной книги повторно проверять формулы и визуально все
листы. При изменении MCP сохранять только read-only инструменты и выполнять
сквозной тест на официальном MOEX ISS.
