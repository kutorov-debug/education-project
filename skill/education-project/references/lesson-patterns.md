# Гибкие сценарии занятия

## Общий каркас

Сохранять последовательность:

```text
Активация → один ближайший элемент → решённый пример → практика → итог
```

Менять длительность и глубину по цели, доступному времени и состоянию ученика.
Не превращать минуты в обязательную норму.

## Короткое повторение: 10–20 минут

Использовать между занятиями, после перерыва или при низком запасе сил.

1. Один-два вопроса на активное воспроизведение.
2. Одна короткая задача без нового метода.
3. Разбор первого места затруднения.
4. Запись следующего повторения.

Не добавлять новый материал только потому, что ответ оказался лёгким.

## Обычное занятие: до 60 минут

1. Активировать один связанный навык.
2. Ввести один новый элемент простыми словами и визуальной моделью.
3. Показать полностью решённый пример.
4. Дать одну задачу с подсказками и убрать помощь по готовности.
5. При успехе дать самостоятельный или переносный вариант.
6. Завершить короткой сводкой: навык, статус, ловушка, повторение.

Держать блоки короткими. Не выдавать весь пакет задач заранее.

## Облегчённое занятие: 25–45 минут

Использовать при подтверждённой усталости или после полного рабочего дня.

1. Выбрать повторение либо один небольшой незавершённый шаг.
2. Использовать аннотированный пример или компактную таблицу.
3. Дать одну практическую попытку.
4. Остановиться после достижения ближайшей цели.

Не вводить новый метод в конце и не компенсировать короткое занятие домашним
пакетом задач.

## Планирование

Перед занятием назвать:

- один наблюдаемый результат;
- текущий пробел-предпосылку;
- выбранный сценарий и причину;
- точку остановки;
- способ проверки без подсказки.

По ходу разрешено менять сценарий, но не подменять цель новым материалом.

## Итог

Показать не больше одной компактной визуальной сводки:

| Поле | Запись |
|---|---|
| Сегодня | Что ученик сделал |
| Статус | Текущий подтверждённый статус |
| Ловушка | Один ближайший риск ошибки |
| Следующий шаг | Один навык или повторение |

Не считать завершённость плана доказательством освоения.
