# Рубрики освоения и готовности

## Содержание

- Назначение и карточка свидетельства
- Общие переходы и профиль качества ответа
- Предметная калибровка
- Практика с риском

## Назначение

Использовать рубрики для изменения учебного статуса и оценки готовности к
следующему типу практики. Не выводить статус из общего впечатления, одного
ответа или среднего балла, скрывающего критический пробел.

## Карточка свидетельства

Для каждого проверочного действия фиксировать:

| Поле | Что записать |
|---|---|
| Навык | Одно наблюдаемое действие |
| Условие | Тип задачи и изменённый элемент |
| Помощь | Нет / короткая подсказка / явные шаги / показанное решение |
| Результат | Ответ и первый существенный сбой |
| Объяснение | Почему выбран метод |
| Контроль | Единицы, знак, масштаб, допущения или тест |
| Дата | Когда получено свидетельство |
| Повторение | Когда проверить без предварительного показа |

Самооценку хранить отдельно от наблюдаемого свидетельства.

## Общие переходы

### `не начато` → `введено`

Требовать, чтобы ученик мог распознать новое понятие или действие после
объяснения и связать его с уже известным. Не требовать самостоятельного решения.

### `введено` → `практика с подсказками`

Требовать выполнения ближайшего действия по явным шагам. Ошибка допустима, если
ученик понимает смысл исправления и может повторить шаг на близком примере.

### `практика с подсказками` → `самостоятельно`

Проверить на новых данных без подсказки и показа решения:

- выбран правильный введённый метод;
- ход объяснён своими словами;
- результат, единицы и допущения согласованы;
- выполнена уместная самопроверка;
- успех не является повторением только что показанного ответа.

Не задавать универсальное число правильных задач. Для простого низкорискового
действия может хватить нескольких независимых свидетельств; для рискованного
решения нужны разные сценарии и отсроченная проверка.

### `самостоятельно` → `перенос подтверждён`

Изменить один существенный элемент — числа, контекст или форму представления —
без добавления нового метода. Требовать самостоятельного выбора уже освоенного
метода и объяснения, что изменилось, а что осталось прежним.

### Любой статус → `нужно повторить`

Понижать не «в наказание», а при утрате самостоятельности после задержки,
повторяющейся концептуальной ошибке или обнаруженном пробеле в предпосылке.
Записывать точную причину и ближайший восстановительный шаг.

## Профиль качества ответа

Оценивать по отдельным критериям:

| Критерий | Подтверждено | Частично | Не подтверждено |
|---|---|---|---|
| Точность | Существенных ошибок нет | Есть некритичная неточность | Неверен смысл или метод |
| Самостоятельность | Без новой помощи | Минимальная подсказка | Явные шаги или ответ показаны |
| Объяснение | Метод обоснован своими словами | Обоснование неполное | Только ответ или повтор текста |
| Контроль | Уместная проверка выполнена | Проверка начата | Проверки нет |
| Перенос | Изменение распознано и обработано | Нужен вопрос-наведение | Новый контекст разрушает метод |

Не складывать критические критерии в компенсирующий средний балл. Неверный метод
или отсутствие обязательного ограничения блокируют переход независимо от суммы.

## Предметная калибровка

В `topic-<тема>.md` определить:

1. цену существенной ошибки;
2. обязательные навыки, которые нельзя компенсировать другими;
3. разнообразие проверочных сценариев;
4. необходимость отсроченной проверки;
5. границу между учебной компетенцией и реальным внешним решением.

## Практика с риском

Для денег, здоровья, права, безопасности и других рискованных областей вести
матрицу готовности:

| Обязательная компетенция | Статус | Свидетельство | Нерешённый риск |
|---|---|---|---|
| Предметная механика | статус | действие и дата | пробел |
| Ограничения модели | статус | объяснение и дата | пробел |
| Ошибки исполнения | статус | сценарий и дата | пробел |
| План остановки | статус | проверенное действие | пробел |

Наличие всех учебных свидетельств означает только подтверждение компетенций.
Оно не является разрешением агента на действие, обещанием результата или
автоматическим выбором финансового лимита. Финальное решение и конкретные
ограничения остаются за пользователем и применимыми внешними правилами.

Если пользователь просит назвать «безопасный процент» до подтверждения ворот,
не подменять отказ числом `0%` и не назначать другой процент. Сообщить, что
учебная готовность не подтверждена, перечислить ближайшие пробелы и продолжить
бумажную практику. После подтверждения ворот всё равно обсуждать лимит отдельно,
не выводя его из учебного балла.
